Schedule Snap（仮）

サービス概要

Schedule Snap は、幼稚園・保育園・学校などから配布される予定表をスマートフォンで撮影するだけで、AIが予定を読み取り、Googleカレンダーへ簡単に登録できるWebアプリです。

紙の予定表を一件ずつ手入力する手間をなくし、忙しい保護者のスケジュール管理をサポートします。

⸻

サービスへの思い・作成理由

子どもが幼稚園に通い始めてから、毎月のお便りや年間行事予定表など、多くの紙の予定表を受け取るようになりました。

予定を忘れないようにするためには、Googleカレンダーへ一件ずつ登録する必要があります。

しかし、以下のような予定を毎回手入力することは、忙しい保護者にとって大きな負担になります。

* 夏祭り
* お弁当の日
* 午前保育
* 保護者会
* 遠足
* 発表会

また、入力を後回しにしてしまい、予定の登録を忘れてしまうこともありました。

そこで、

「予定表を撮影するだけでAIが内容を理解し、Googleカレンダーへ登録できれば、保護者の負担を減らせるのではないか」

と考え、このサービスを作成しました。

⸻

ユーザー層

* 幼稚園・保育園に通う子どもがいる保護者
* 小学校低学年の子どもがいる保護者
* 家族の予定をGoogleカレンダーで管理している方
* 紙の予定表をデジタル管理したい方

⸻

サービス利用イメージ

1. 幼稚園・保育園・学校から配布された予定表を撮影
2. AIが画像から予定を抽出・解析
3. 抽出された予定を一覧で確認
4. 必要に応じて内容を編集
5. Googleカレンダーへ登録

⸻

推しポイント・差別化ポイント

* AIが予定表の内容を解析し、予定を自動抽出
* Googleカレンダーへワンクリックで登録
* OCRによる文字認識だけではなく、AIが予定内容を理解して整理
* 登録前に内容確認・編集が可能
* 保育園・幼稚園・学校特有の予定にも対応

例：

* お弁当の日
* 午前保育
* 保護者会
* 遠足
* 行事予定
